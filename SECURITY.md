# Security And Privacy

## Privacy Defaults

- No telemetry is collected by default.
- Settings are stored locally in app data.
- Logs should avoid track history, note contents and transcription text.
- Future cloud integrations must be opt-in.

## Reporting Issues

Open a private security advisory on GitHub, or contact the maintainer on Telegram: [@redheadesign](https://t.me/redheadesign) (Russian & English).

Please include:

- App version.
- Windows version.
- Reproduction steps.
- Whether the issue requires a specific media player.

Do not include private notes, transcription text or account tokens in reports.
