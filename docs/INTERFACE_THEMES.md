# Interface themes

Glass adapts the frosted rim, low-density particles, button sheen and ASCII scenes from [the T3 Code design work](codex://threads/01a1decb-6424-7e60-b40f-38835bc1774a). It uses the current Music Island layouts and actions. Fresh profiles start with Glass. Existing profiles switch to Glass once on the first start after this update. A later choice of Classic persists across restarts. Glass opens with foxes unless a preview scene has already been chosen. The settings color scheme, color palette and dictation artwork are separate choices.

The system follows the [Uber Base Web theme model](https://github.com/uber/baseweb/blob/main/documentation-site/pages/guides/theming.mdx): theme inputs resolve to semantic roles that production components consume. Glass follows [Apple’s materials guidance](https://developer.apple.com/design/human-interface-guidelines/materials) in keeping text areas legible and honoring reduced transparency.

Glass uses Segoe UI Variable Text and the system fallback stack for the Windows UI. Settings controls have a shallow 3.5 px blur. The island transport, reactions, settings and pin controls use a more transparent tint derived from the satellite material and a local backdrop blur. On hover, one masked SVG filter bends the WebView backdrop around the rim. The icon or label stays outside the filter. Reduced motion, reduced transparency and forced colors disable pointer tracking. The text and local-server widgets below the island use fill and depth for separation. [Liquid Glass Button reference](https://21st.dev/@designali-in/components/liquid-glass-button)

The compact ASCII fox scene distributes four to six foxes across two lanes. Both animal scenes keep the same 24 fps cap. In the expanded player, soft waves expand outward from the center under the controls and take on the cover colors. The hover cue at the upper screen edge grows before expansion and follows the pointer. Hidden documents pause the waves and particles. Reduced motion leaves a static wave layer and hides particles. Reduced transparency disables both effects. [Shader Animation reference](https://21st.dev/@designali-in/components/shader-animation)

Appearance → Background and behavior has a single playback background switch. The classic wave expands from the center in the artwork colors. The transport and seek bar keep their artwork colors when the wave is off.

On supported Windows versions, the wave follows the bass automatically when the configured Direct Yandex player is playing and the island is open. Only audio from the verified player process is analyzed. The visual layer receives a normalized level. Pausing, hiding the island, turning off its background or reducing motion stops the audio worker. The quiet falling particles and the cover colors are independent of both the wave switch and the bass level. Profiles previously using Direct without process-audio consent start with the switch off. [Windows application loopback](https://learn.microsoft.com/en-us/samples/microsoft/windows-classic-samples/applicationloopbackaudio-sample/)

The neutral dark ramp comes from the Codex screenshot. The canvas uses `#232322`, content uses `#2d2d2b` and raised controls use `#353533`. Floating menus and secondary buttons use a translucent face. Passive settings groups share the window canvas and align to one inset. Dialogs and preview stages retain their own reading surface. The scope and language tracks use 45%. Menus open from the edge nearest the trigger. Glass uses the cover's original colors for accents and a distinct second hue when the artwork contains enough of it. The full-height seek fill keeps one cover hue, fitted in sRGB for at least 4.7:1 contrast with the title. The two ends differ by a 4% tint, so dark or complementary artwork cannot introduce a brown band in the middle. Both progress indicators fall back to neutral without usable artwork. [Motion review](TRANSITIONS_MOTION_REVIEW.md)

Color presets use T3 Code's side-by-side light and dark previews. Each preset has a primary and a secondary color in both schemes. The existing custom accent remains available under its own option. Material, color palette and preview scene are saved separately.

The implementation agent owns preference integration and component reuse, the motion agent owns the shared renderer, and an independent reviewer verifies each stage. The design lead owns visual direction, Storybook coverage and integration.

The material picker precedes the layout editor even at the minimum 620 × 480 window size. Direct remains an explicit choice on the source page. Its consent dialog explains the local audio analysis.

Both workshop and application use the same default theme. The standalone editor, Better Voice and dictation stories mount the same scene provider as the settings window. Themes declare support for the playback wave in the registry. Switching to Classic suspends the wave. Returning to Glass restores its saved on/off setting. Buttons and sliders share a palette value role. The lower island widgets keep their text at full opacity over a separate reading surface. Increased contrast makes that surface opaque and attenuates the decorative playback layer.

To add a theme, add one stable ID to `INTERFACE_THEMES` in `src/shared/lib/interfaceTheme.ts`. Set `material` to `classic` or `glass`, write the label in both languages, and supply any shared `roles` or per-scheme overrides in `schemes.dark` and `schemes.light`. These can change an existing role such as `--font-sans`, `--space-unit`, `--control-height`, `--radius-unit` or `--surface-raised`. The CSS build expands the base material selectors to all derived theme IDs and emits their roles onto the same window and portal roots. Native playback windows use the dark scheme. A theme may opt into a scene or playback renderer through its registry entry.

The Foundations / InterfaceTheme workshop mounts a third theme in a real SettingsWindow, taskbar player and a Select menu portalled to the document. Its fixture lives only in the Storybook build and checks typography, derived spacing, control height, scheme colors and the inherited glass filter. Review new themes with a production component at native window sizes.
