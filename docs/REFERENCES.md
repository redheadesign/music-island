# References

- [NoraBar](https://github.com/mtmtyu/NoraBar): top-edge Windows music HUD with hover reveal behavior.
- [windows-notch-overlay](https://github.com/Taxperia/windows-notch-overlay): Windows Dynamic Island style reference.
- [nowplaying-widget](https://github.com/DarkishLocket10/nowplaying-widget): Rust-oriented now playing widget with skins and controls.
- [node-windows-smtc-monitor](https://github.com/LeagueTavern/node-windows-smtc-monitor): event-driven SMTC monitoring reference.
- [RuFlow](https://github.com/westik86-sys/RuFlow): product feel and future transcription inspiration.
- [Tauri updater](https://v2.tauri.app/plugin/updater/): signed auto-update path.
- [tauri-action](https://github.com/tauri-apps/tauri-action): GitHub Actions release automation.

This project should not copy visual assets, branding or code from the references unless their licenses explicitly allow it.
