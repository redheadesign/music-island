В `SettingRow` группа связана с названием через `aria-labelledby`; контролы
получают доступные названия без оборачивания нескольких действий одним `label`.
`SettingsIconButton` требует название и подсказку. `Notice` использует `alert`
для ошибки и `status` для остальных состояний. Пустое/некорректное числовое поле
возвращает сохранённое значение. Прослушивание ждёт сохранения громкости.

### Профиль Warp

Один сравнительный проход Storybook, 12 переходов по четырём геометриям,
первые посещения и повторы. Измерение — от переключения до двух requestAnimationFrame,
в dev-браузере; параллельно могла идти сборка. Это диагностический замер,
не замер GPU и не подтверждение задержек native-приложения.

| Вариант | Новых canvas за 12 переходов | Медиана, мс |
| --- | ---: | ---: |
| Прежнее владение, remount | 12 | 68,0 |
| Постоянный владелец | 0 | 33,0 |

Данные: `warp-before.json` и `warp-after.json` в папке проверки.
При скрытии превью renderer переходит в `paused` без уничтожения canvas.
Повторный production-профиль на Windows нужен для оценки первого открытия,
оставшихся задержек страниц и потребления скрытого окна.

## Сочетания клавиш и точка в конце

По сообщению пользователя portable зависала на «Нажмите сочетание…». UI ожидал только handy-keys-event и не обрабатывал события клавиатуры окна. Запись сочетания переведена на keydown/keyup WebView; нативные suspend/change/resume по-прежнему отвечают за регистрацию. Операции сериализованы при смене полей, восстановление выполняется при отмене, blur, размонтировании и ошибке сохранения. Физические коды не зависят от RU/EN; для Handy Keys сохраняются стороны модификаторов.

Добавлен remove_trailing_period, выключен по умолчанию, в «Дополнительно → Вставка текста». Удаление применяется к итоговому тексту после ИИ, также при повторном распознавании из истории. Исходная транскрипция сохраняется; итог без точки доступен в истории и overlay/copy fallback.
