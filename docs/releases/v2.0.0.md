# Music Island 2.0.0

Music Island 2.0 turns the portable Windows media island into a configurable
workspace for playback, taskbar controls, usage limits and Better Voice.

## Highlights

- **Build your island:** drag player controls, artwork, progress, reactions,
  Codex/Claude widgets and actions into protected zones. Resize the live preview;
  the resulting layout and scale are saved.
- **Native taskbar player:** place an optional compact player beside the notification
  area of the primary horizontal Windows taskbar and choose the order of artwork,
  Previous, Play/Pause, Next, Like, Shuffle and Repeat.
- **Capability-aware playback:** Shuffle and Repeat are available only when the
  active media session supports them, including Repeat All and Repeat One states.
- **Spotify through Windows:** select Spotify as the preferred SMTC source without
  connecting a Spotify account to Music Island.
- **Codex and Claude limits:** enable either provider separately to show sanitized
  remaining-quota and reset information in compact or detailed widgets. Codex
  uses its installed local app-server; Claude uses the existing local Claude Code
  sign-in to query Anthropic directly.
- **More coherent surfaces:** the island, assistant satellites and active My Wave
  chip now share the same artwork-aware material.
- **Smoother track changes:** progress keeps one track identity when duration
  metadata arrives late and coalesces rapid navigation updates without replaying
  the transition.
- **Better Voice:** refined routing, device setup, effects, meters and guidance for
  the in-process voice engine.
- **New Settings experience:** refreshed light and dark themes, clearer navigation,
  keyboard-accessible editors, reduced-motion support and broader Storybook
  coverage of production UI.

## Privacy and local behavior

Direct Yandex Music and each usage provider remain explicit opt-ins. Usage polling
is disabled until a provider is connected and stops when it is disabled. Music
Island does not show authentication secrets, report monetary cost or claim to
represent all ChatGPT usage. Spotify playback uses the media session already
published to Windows SMTC. Codex relies on the local app-server login without
reading its auth files. Claude reads the existing Claude Code OAuth credential
only after its separate opt-in and sends it directly to Anthropic's usage endpoint;
there is no Music Island account service or proxy.

## Upgrade and compatibility

Music Island 2.0 supports Windows 10 and Windows 11 and remains a single portable
`music-island.exe`. Replace the previous executable; settings under
`%APPDATA%\Music Island\` are preserved and older layout preferences are migrated.

The executable is unsigned, so Windows SmartScreen may show a warning. Better
Voice requires a compatible virtual audio cable such as VB-Cable. Available media
commands depend on the capabilities published by the active player.

Portable updates now require the release's `SHA256.txt` and verify the downloaded
executable's SHA-256 and PE header before replacement.
