## Music Island 3.3.0

**GigaAM-v4 is now the first recommendation for Russian dictation.** In **Settings → Dictation → Models**, download **255 MB** to transcribe when you finish recording. For words as you speak, turn on **Live transcription package** on the same card, install it and choose the **Live** recording overlay. The extra files add **966 MB**, for **1.22 GB** in total. Both modes also support English and run on your PC.

- **Dictate in 21 languages.** GigaAM Multilingual-v2 supports live dictation and recorded speech in languages including Kazakh, German, Italian and Portuguese. Its optional download is **3.93 GB**.
- **Compare models before downloading.** Model cards show which modes are available, alongside speed and accuracy bars. GigaAM-v4 shows published benchmarks for recorded speech. Models from Handy use its catalog ratings.
- **Click as soon as the island opens.** Move the pointer to the top edge and use playback controls while the desktop glass warms up. Moving away during opening now closes the island reliably.
- **Recover from interrupted dictation.** Model downloads recover when a server ignores a resume request. Music Island reports silent microphone input and lets you copy the transcript when Windows blocks pasting into an app running as administrator.

To update, open **Settings → About** or download **music-island.exe** below. Dictation models download separately.
