# Music Island 3.0.1

Небольшое обновление с исправлениями диктовки и более аккуратными настройками.

## Диктовка

- Исправлено зависание поля «Нажмите сочетание…» при изменении сочетаний клавиш.
- Добавлена настройка **«Убирать точку в конце»**: Диктовка → Дополнительно → Вставка текста. По умолчанию выключена; остальные знаки и многоточия сохраняются.
- На основной странице появилось живое компактное превью. Сочетания клавиш собраны сразу под ним.
- Дополнительные параметры сгруппированы; громкость, значение и прослушивание сигнала находятся в одной строке. Исправлена обработка пустых числовых полей.
- Карточки моделей стали компактнее. Выбранная модель отмечена зелёным, удаление — отдельной иконкой, импорт из Handy перенесён в меню добавления модели.

## Внешний вид и удобство

- Обновлены цвета Paper Warp. Включённые превью больше не выглядят приглушёнными; выключенные используют общее затемнение. Ускорение фона при включении стало мягче.
- Анимированный фон больше не создаётся заново при каждом переходе между страницами настроек.
- Выровнены отступы мини-плеера, индикаторы перетаскивания используют выбранный акцент. Масштаб мини-плеера и лимитов меняется угловым маркером, как у островка.
- Подписи ширины и масштаба перенесены под превью. Убраны лишние кнопки сброса; верхний сброс мини-плеера возвращает состав и масштаб.
- Переработаны карточки лимитов ИИ, уведомления, история диктовки, источник музыки и раздел «О программе». В Better Voice восстановлена поверхность блока «Обработка».
- Удалён переключатель показа лимитов при закрытом островке.

Скачайте `music-island.exe` или обновитесь через раздел «О программе». Установка не нужна, существующие настройки сохраняются.
