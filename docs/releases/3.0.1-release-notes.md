# Music Island 3.0.1

A small update with dictation fixes and cleaner settings.

## Dictation

- Fixed shortcut capture getting stuck on “Press a shortcut…” when changing keyboard shortcuts.
- Added **Remove trailing period** under Dictation → Advanced → Text insertion. It is off by default and preserves other punctuation and ellipses.
- Added an animated compact preview to the main dictation page, with keyboard shortcuts grouped directly below it.
- Grouped advanced settings and combined sound volume, its value and the preview action into one row. Fixed handling of empty numeric fields.
- Made model cards more compact. The selected model is highlighted in green, deletion uses a dedicated icon, and Handy import is now in the model menu.

## Appearance and usability

- Updated the Paper Warp colors. Enabled previews now show their full color, disabled previews share the same dimmed appearance, and enabling a feature increases the animation speed more gently.
- The animated background is reused when switching settings pages instead of being recreated on each visit.
- Balanced the taskbar mini-player's left and right padding. Drag indicators follow your accent color. The mini-player and assistant-limit previews now use corner resize handles, matching the main island.
- Moved width and scale labels below the previews and removed duplicate reset buttons. The mini-player's top reset restores both its layout and scale.
- Refined assistant-limit cards, notifications, dictation history, music sources and About. Restored the background of the Processing block in Better Voice.
- Removed the option to show assistant limits while the island is closed.

Download `music-island.exe` or update from About. No installation is required, and your existing settings are preserved.
