# Music Island 3.0.4

- Roll back the Windows clipboard insertion mechanism introduced in 3.0.3 after reports of failed insertions and clipboard replacement during consecutive dictations.
- Finish insertion and clipboard restoration before allowing the next recording to start.
- Skip saved clipboard restoration when Windows reports a newer clipboard change during insertion.
- Add a bounded local dictation lifecycle log and native panic backtraces for troubleshooting. Dictated text and clipboard contents are excluded from the new log.

The Fox default, theme order, compact Classic layout and rendering improvements from 3.0.3 remain. This is a conservative insertion rollback; the earlier fixed-delay limitation when a target application stalls remains under investigation.

Existing settings and downloaded models remain compatible.
