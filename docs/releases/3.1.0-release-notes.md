## Music Island 3.1.0

- Fixed a Windows freeze when opening model storage in File Explorer. Opening dictation logs, recordings, or the app data folder now keeps the interface responsive.
- Choose Vulkan, CPU, or automatic acceleration for supported dictation models. Vulkan can use a specific graphics card when more than one is available.
- Optionally show the latest transcript below the expanded island. Copy or dismiss it there; the original stays in History.
- Add the Local Servers widget to open or stop supported local development servers from the expanded island.
- Find your active or recommended model above the catalog and see which models are downloaded. Settings use shorter labels and show scale beside the resize handle when you need it.

Download `music-island.exe` for Windows 10 or 11. No installer is required. Your existing settings, recordings, and downloaded models stay in place.
